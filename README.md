# Le Biscotto Nancy

Site vitrine one-page pour un restaurant italien fictif, créé comme premier
template réutilisable pour la vente de sites vitrines à des clients (restaurants,
salons, artisans...).

## Stack
- HTML / CSS pur (pas de framework, pas de dépendances)
- Responsive (mobile-first)

## Structure
- `index.html` — contenu et structure de la page
- `style.css` — design (couleurs terracotta / vert olive, thème italien)
